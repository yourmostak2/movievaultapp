# Contributing to Movie Vault

Thanks for helping make Movie Vault better! Every kind of help is welcome: bug reports, ideas, translations and design feedback.

## 🐞 Report a bug
Open an [issue](../../issues/new) and include:
- What you did and what you expected to happen
- What actually happened (a screenshot helps a lot)
- Your phone model, Android version and the app version (Settings → Check for updates)

## 💡 Suggest a feature
Open an issue titled `Idea: …` and describe what you would like and why. Please check existing issues first to avoid duplicates.

## 🌍 Help with translations
Movie Vault supports many languages. If a word looks wrong or missing in your language, open an issue with the original text and your suggested translation.

## 🔧 Send a pull request
1. Fork this repository and create a branch (`git checkout -b my-change`)
2. Make your change. Keep it small and focused
3. Test it on a real phone or in a browser
4. Open a pull request and explain what changed and why

## 📐 Guidelines
- Be kind and respectful to everyone
- Never commit API keys, passwords or signing keys
- Keep the app simple, fast and easy to use

## 🔒 Security
Found a security problem? Please do not post it publicly. Contact the maintainer privately through GitHub instead.
